# Events service

Проект Events service - cервис мероприятий

## Запуск приложения
В рабочем окружении должен быть установлены docker и docker-compose для установки и запуска приложения.

Для установки и запуска необходимо выполнить следующие шаги:

1. Скачать репозиторий на компьютер с установленным docker-compose

2. запустить команды `make init`
   Данная команда скачает все необходимые образы, соберет и поднимет все контейнеры, установит все зависимости vendor и применит миграции.

После, на порту `90` должно запуститься приложение.

## Полезные команды
| Действие                                  | Команда            |
|-------------------------------------------|--------------------|
| Инициализация приложения                  | `make init`        |
| Запуск приложения                         | `make start`       |
| Остановка приложения                      | `make down`        |
| Принудительное обновление контейнеров     | `make build`       |
| Очистка приложения от бд, var и vendor    | `make clear`       |

## Наполнение данными
После создания окружения и заполнения .env

1. Создать бд `bin/console doctrine:database:create`
2. Выполнить миграции `bin/console doctrine:migrations:migrate`
3. Получить свойства для мероприятий `bin/console app:update-props`
4. Заполнить таблицы тестовыми данными `bin/console app:test-data`
